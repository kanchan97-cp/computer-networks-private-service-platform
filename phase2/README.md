# Phase 2 – Private Service Platform

## Overview
This directory contains the configurations, documentation and evidence for Phase 2 of the Computer Networks private service platform project.

## Extensions
- DNS TTL configuration and verification
- Client DNS cache behavior
- Firewall restrictions on direct backend access
- Nginx access after firewall implementation
- Backend failover and recovery
- Standby Nginx configuration
- DNS cutover
- Troubleshooting and fault recovery

## Directory Structure

### configs/
Contains reference configuration files for DNS, Nginx, firewall testing and standby proxy configuration.

### docs/
Contains the Phase 2 implementation report, failover procedure and troubleshooting record.

### evidence/
Contains screenshots of the actual tests and implementation.

## Testing
The configurations and tests are intended to be validated on the actual network hosts before final submission.

## Project Outcome
Phase 2 extends the private service platform with additional access restrictions, DNS testing, backend availability and recovery demonstrations.
